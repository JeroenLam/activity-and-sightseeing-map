# Activiteiten Mobile

A mobile-first companion interface for the Activiteiten & Bezienswaardigheden Tracker.

## Focus
- Offline local cache for locations, types, and settings
- Queueing mutations while offline
- Syncing through the backend sync endpoints when online
- Compact interface for Android/WebView packaging later

## Scripts
- `npm run dev`
- `npm run build`
- `npm run type-check`
